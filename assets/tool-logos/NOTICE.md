Tool logos identify their respective products; trademarks remain with their owners.
The exact source URL for each asset is recorded in `sources.json`.

- Common developer-tool artwork: [Devicon](https://github.com/devicons/devicon), MIT license retained in `DEVICON-LICENSE.txt`.
- AWS service artwork: [AWS Labs architecture icons](https://github.com/awslabs/aws-icons-for-plantuml); [AWS icon guidance](https://aws.amazon.com/architecture/icons/).
- Docker Compose, Trivy, Checkov, TruffleHog, and KubeLinter: artwork from the respective official project repositories or assets referenced by those projects.
- GitOps: the [OpenGitOps mark published by CNCF](https://github.com/cncf/artwork/tree/main/projects/opengitops).
- Waving hand: [Twemoji](https://github.com/jdecked/twemoji), graphics licensed under CC BY 4.0; see `TWEMOJI-LICENSE-GRAPHICS.txt`.

Only the icon region of the KubeLinter vertical logo is displayed. Trivy's non-rendering Adobe editor metadata was removed. The card generator renders small embedded copies of these assets for consistent, self-contained display.
